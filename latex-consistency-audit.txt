Findings

1. Update the cover letter's description of the model.
   File inside archive: submission_stuff/cover_letter.tex:15 and :21.

   The letter says the target class is "all mean-square integrable martingales"
   and describes approximating the terminal price itself by a chaos expansion.
   The active manuscript instead models S_T = S_0 X_theta^2, normalizes
   E[X_theta^2] = 1, and proves terminal-L1 universality for integrable,
   nonnegative Brownian martingales. Square integrability of the target terminal
   PRICE is unnecessary, and arbitrary signed martingales are outside this class.
   The chaos expansion approximates sqrt(S_T/S_0), rather than S_T itself.

   Suggested replacement for the model-description portion of paragraph 2:
   "Assuming Brownian noise, we construct nonnegative martingale models from the
   normalized square of a finite Wiener chaos expansion. The resulting class is
   universal in terminal L1 among integrable nonnegative Brownian martingales.
   We approximate the square root of the normalized terminal price and recover
   the intermediate price process by conditional expectation. The Hermite
   polynomial representation yields explicit conditional-square formulas for
   efficient calibration to option prices."

   Replace the "main constraint being mean-square integrability" wording in the
   first contribution with the integrability and nonnegativity assumptions above.

2. Soften the cover letter's fit claims.
   File inside archive: submission_stuff/cover_letter.tex:17.

   "Essentially exact calibration" and "essentially perfect fit" overstate the
   numerical results. Across studies, calibration MAEs are about 4–10 volatility
   basis points; SPX study means are 8.86 and 10.29 bps. The recorded fraction of
   SPX fits inside the quoted bid-ask interval averages 56.71% and 46.82%,
   respectively. These support "accurate fits" or "close fits", without implying
   exact reproduction or that essentially all fitted values are within the
   observed spreads. The active manuscripts already use more measured wording.

3. Complete or remove the submission date placeholder.
   File inside archive: submission_stuff/ex_shared.tex:40.

   "Submitted to the editors DATE." appears literally in the compiled SIAM PDF.
   The actual submission date cannot be inferred from the project.

4. Qualify the rough-Heston memory statement (minor).
   File inside archive: main.tex:1140; submission.tex:1119.

   The paragraph permits alpha = 1 and correctly says that this gives classical
   Heston, but immediately says "The kernel introduces memory into the variance
   process, so the model is no longer Markovian." Qualify this by alpha < 1:
   "For alpha < 1, the kernel introduces memory into the variance process, so
   the model is no longer Markovian."

5. State the training Monte Carlo budgets explicitly (reproducibility improvement).
   File inside archive: main.tex:1369 and the following pricing tables;
   corresponding appendix in submission.tex.

   The appendix correctly identifies its budgets as independent EVALUATION
   budgets. These are not always the budgets used inside the optimizer:
   - Rough Heston / Legendre: 2M training paths versus 4M evaluation paths at
     the shortest calibration maturity.
   - SPX / piecewise constant: 400k training versus 200k evaluation paths at
     maturities 3–4, and 200k training versus 100k evaluation paths at 5–10.
   - SPX / Legendre: 400k training versus 200k evaluation paths at maturities
     1–4, and 200k training versus 100k evaluation paths at 5–10.
   These are omissions, not incorrect entries in the present evaluation tables.
   The other training allocations match the stated evaluation allocations.

Calibration and formula checks

Verified against source and recorded configurations:
  - Hermite convention H_n = He_n/n!, derivative H_n'=H_(n-1).
  - Coefficient normalization sum_a d_a^2/a! = 1.
  - Piecewise normalized indicators and Brownian increment convention.
  - Shifted, normalized Legendre family.
  - Vega weights 1/Vega^2; mean versus sum changes only a fixed objective scale.
  - AdamW, zero weight decay, initial learning rate 1e-4.
  - Iteration caps, plateau scheduler, stopping tolerances and patience.
  - Paths refreshed every 50 iterations; degree-2 controls use the pricing sample.
  - Checkpoint selection by monitored training loss within the stated tolerance.
  - Separate Monte Carlo samples for reported evaluation.
  - Evaluation path budgets and Gauss-Hermite node counts in all five tables.
  - Heston exotic payoff definitions, forward start dates and monitoring step.

  - Both bases, P=2 and P=3, two drivers and two time functions.
  - Four observation times, including a piecewise grid boundary and the horizon.
  - Conditional-square values compared with direct exact Gaussian quadrature of
    the squared Hermite polynomial.
  - First and second stock moments compared with exact Gaussian quadrature.
  - All three manuscript Black-Scholes exotic formulas compared with project
